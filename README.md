# GitHub Repository Analyzer

A FastAPI backend application that integrates with the GitHub REST API to analyze repositories and store repository metrics in a MySQL database.

## Technologies

- Python
- FastAPI
- SQLAlchemy
- MySQL
- GitHub REST API

## Features

- Analyze GitHub repositories
- Store repository statistics
- View repository history
- Repository ranking by stars
- Aggregated analytics

## Run

pip install -r requirements.txt

uvicorn main:app --reload
